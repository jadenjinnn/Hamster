## What it is

Hamster is a 2D game engine for Windows. You build scenes in a visual editor — placing sprites, setting up physics, slicing spritesheets — and write the gameplay logic in **Python**. A Python class drives each entity; the C++ runtime calls it every frame. Press **Play** and the game runs in its own window.

<CardGrid>
	<Card title="Gameplay in Python" icon="pencil">
		Subclass `HamsterBehaviour`, implement `on_create` and `on_update`, and the engine runs your code per entity. Read input, apply forces, spawn entities, look others up by name.
	</Card>
	<Card title="Native C++ / OpenGL core" icon="setting">
		An EnTT entity-component-system, a batched OpenGL renderer, and a quadtree spatial index for culling and picking. Python is embedded via pybind11.
	</Card>
	<Card title="Visual editor" icon="puzzle">
		Scene hierarchy, property inspector, asset browser, spritesheet slicer, and a keyframe animation timeline. Non-destructive play mode — Stop reverts everything.
	</Card>
	<Card title="Box2D physics" icon="rocket">
		Rigidbodies (static / dynamic / kinematic), box and circle colliders, gravity, forces, and impulses, exposed straight to your Python scripts.
	</Card>
</CardGrid>
